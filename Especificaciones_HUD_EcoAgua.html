Especificaciones Técnicas y de Diseño UI/UX: HUD EcoAgua

Proyecto: EcoAgua
Motor: Godot Engine 4 (Soporte PC, Web y VR/WebXR)
Objetivo: Diseño del sistema de interfaz de usuario (HUD) para visualización de parámetros de calidad de agua por zonas.

1. Visión General del HUD

El HUD mostrará en tiempo real los parámetros físico-químicos y biológicos del agua según la zona del río en la que se encuentre la sonda o jugador. Dado que los parámetros varían por zona, la interfaz debe ser modular y dinámica (mostrar u ocultar tarjetas/filas según los datos disponibles).

Estructura y Jerarquía Visual Sugerida

  1. Elemento Principal / Destacado:
    • Índice de Calidad del Agua (ICA): Es el indicador global (valor numérico de 0 a 100). Debe ser el elemento visualmente más llamativo (por ejemplo: indicador circular tipo dona o tarjeta principal con código de color dinámico según la gravedad).
  2. Encabezado de Ubicación:
    • Indicador textual de la zona actual (ejemplo: "Sonda de Medición - Zona 1").
  3. Panel de Parámetros Específicos:
    • Lista o grilla modular de tarjetas/filas compactas conteniendo: [Icono] [Nombre Parámetro] [Valor + Unidad].

3. Requerimientos de Assets y Formatos de Entrega

Para poder integrar los diseños en Godot 4, los elementos deben entregarse despiezados (export por capas/assets individuales) y no montados en una sola imagen fija.

A. Archivos y Formatos Principales

  • Assets gráficos: Archivos .png individuales con fondo transparente (canal Alpha).
  • Tipografías: Archivos .ttf o .otf de las fuentes utilizadas en la interfaz (para poder generar los textos numéricos dinámicos desde código).
  • Mockup de referencia: Un archivo .png o PDF del HUD completo armado en resolución 1920x1080 px (sirve como guía de posición, fuentes y espaciado).

B. Listado Desglosado de Assets Solicitados

  1. Iconografía (256x256 px o 128x128 px, PNG transparente):
    • Icono para Oxígeno Disuelto (ejemplo: moléculas de O2, burbujas).
    • Icono para Nutrientes / Nitratos / Fosfatos / Amonio (ejemplo: frasco de laboratorio, compuesto químico).
    • Icono para DBO (ejemplo: curva de demanda de oxígeno / prueba biológica).
    • Icono para Coliformes Fecales / Bacterias (ejemplo: microorganismo / germen).
    • Icono para Metales Pesados / Cromo (Cr) (ejemplo: símbolo de toxicidad química / gota de metal).
  2. Fondos y Paneles (Compatibles con 9-Slice / NinePatchRect):
    • Fondo para la tarjeta principal (Panel del ICA).
    • Fondo para las tarjetas o filas de los parámetros.
    • Nota: Si tienen bordes redondeados o sombras, enviar la textura limpia sin deformación previa para configurar las zonas de estiramiento en Godot.
  3. Componentes del Indicador ICA:
    • Anillo / Barra de fondo (estado base deshabilitado).
    • Anillo / Barra de progreso (relleno que se pueda manipular por código).
    • Iconos opcionales de estado o alertas (verde / amarillo / naranja / rojo).
  4. Paleta de Colores (Guía de Estilos):**
    • Definición de códigos HEX o RGB para la escala de gravedad del ICA.
